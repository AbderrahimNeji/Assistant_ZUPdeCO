# Établissements et matières

## Établissements

Un **établissement** est une structure scolaire ou un site rattaché à votre organisation : nom, code UAI, type (collège, lycée, professionnel, autre), adresse, statut. Les établissements servent à situer géographiquement et administrativement les élèves, les séances ou les partenariats selon les usages de votre déploiement.

## Matières

Les **matières** sont les disciplines du référentiel (code, libellé, cycle, description). Elles permettent d’étiqueter les séances, les besoins ou les compétences travaillées. Une matière est définie au niveau de votre **entreprise** (tenant), comme les programmes et les établissements.

## Relation entre établissements et matières

Il n’y a pas de lien technique obligatoire « un établissement = une liste fixe de matières » dans le modèle général : ce sont deux **référentiels indépendants**. En pratique, ils se croisent lorsque vous affectez des élèves ou des séances : une séance peut avoir une matière et concerner des participants rattachés à un ou plusieurs établissements. Pour savoir comment votre structure relie établissements, classes et matières, suivez les écrans de **séances**, **élèves** et **affectations** ou demandez à votre administrateur métier.
