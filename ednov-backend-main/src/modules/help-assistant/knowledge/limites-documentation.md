# Limites de l’aide en ligne

## Pas de détail sur la base de données

L’assistant d’aide est destiné aux **utilisateurs métier** (coordinateurs, administrateurs fonctionnels). Il s’appuie sur une **documentation produit** en langage fonctionnel.

Il **ne décrit pas** : noms de tables SQL, colonnes, clés étrangères, schémas techniques ni requêtes. Ces sujets relèvent de la **documentation technique** ou de votre **équipe d’intégration / développement**.

## Ce que vous pouvez faire

Si vous avez besoin de comprendre **comment utiliser** un écran (Séances, Élèves, Matching, etc.), posez votre question en termes de **menus**, **actions** et **parcours utilisateur**. Pour la structure des données au niveau base, contactez l’administrateur technique ou le support Ednov selon votre contrat.
