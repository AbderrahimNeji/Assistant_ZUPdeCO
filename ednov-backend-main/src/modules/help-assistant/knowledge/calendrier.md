# Calendrier

## Vue Calendrier vs liste Séances

Le menu **Calendrier** du tableau de bord ouvre une **vue temporelle** des créneaux (séances et événements liés selon votre configuration). Il sert à **visualiser** et **anticiper** les créneaux sur une grille de dates.

Le menu **Séances** propose en général une **liste** ou une vue détaillée pour **créer, modifier, filtrer** les séances et gérer les **participants**. Les deux écrans se complètent : le calendrier pour la lecture globale, les séances pour l’action et le détail.

## Navigation

Les chemins d’URL internes sont du type `/dashboard/calendar` pour le calendrier et `/dashboard/sessions` pour les séances. Si vous n’avez pas l’un de ces menus, c’est en général lié à vos **droits** ou à la configuration du menu latéral.
